# Usage Guide

## Vendor Security Questionnaire Template

Use the questionnaire template as a starting point for preparing or reviewing common buyer security questions.

Recommended workflow:

1. Remove questions that are clearly irrelevant to the service being assessed.
2. Add buyer-specific, industry-specific, contractual, or regulatory questions where needed.
3. Map each question to current evidence.
4. Assign unresolved questions to the accountable function.
5. Record the final approved answer separately from the evidence source.
6. Revalidate both the answer and evidence before reuse.

Do not treat the template as a universal control standard or an official industry questionnaire.

## Evidence Library Template

Use the evidence library as an index of approved source material.

For each artifact:

- identify an accountable owner;
- store the current approved location internally;
- record the last review date;
- define the next review date;
- note which questionnaire claims it can support;
- retire superseded versions so old evidence is not accidentally reused.

Avoid storing confidential customer material directly in a public repository.

## Evidence-first response principle

A questionnaire answer should be treated as supported only when current evidence can substantiate the material claim. When evidence is incomplete, contradictory, or outdated, route the question for human review rather than filling the gap with generic language.
