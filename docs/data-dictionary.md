# Data Dictionary

## vendor-security-questionnaire-template.csv

| Column | Meaning |
| --- | --- |
| ID | Stable question identifier |
| Category | Security or governance domain |
| Question | Questionnaire prompt |
| Suggested Evidence | Example artifact that may support an answer |
| Typical Owner | Function that often owns the answer |

## security-questionnaire-evidence-library-template.csv

| Column | Meaning |
| --- | --- |
| ID | Stable evidence identifier |
| Evidence Category | Security or governance domain |
| Evidence Artifact | Policy, procedure, report, diagram, configuration, or other source |
| What It Can Support | Types of questionnaire claims the artifact may substantiate |
| Typical Owner | Function that normally maintains the artifact |
| Review Cadence | Suggested freshness/review interval |

The suggested owner and cadence fields are starting points, not universal requirements.
